## 1. Incident Summary

**Title:** TLS Certificate Expiry on Internal Development Server

On 25 June 2026, an expired TLS certificate on an internal development/staging server caused automated CI/CD pipeline failures for approximately 45 minutes. No production systems or client-facing services were affected. The certificate was renewed and pipelines resumed normally.

## 2. Detection

**Detection Method:** CI/CD pipeline failure alerts in Slack; developer investigated and found certificate expiry.

**Detection Timestamp:** 2026-06-25T14:00:00+02:00

## 3. Timeline


- 14:00 CET: CI/CD pipelines begin failing with TLS handshake errors
- 14:15 CET: DevOps engineer identifies expired certificate on staging server
- 14:30 CET: New certificate issued via internal CA and deployed
- 14:45 CET: Pipelines resume; no production impact

## 4. Affected Systems

- Internal staging/development server
- CI/CD pipeline

## 6. Root Cause Analysis

Certificate renewal reminder was configured to send to a shared mailbox that was not actively monitored. Certificate lifecycle management not integrated with automated renewal.

## 7. Remediation Actions

Renewed certificate; added certificate to automated monitoring and renewal system; updated alerting to page on-call engineer directly.
